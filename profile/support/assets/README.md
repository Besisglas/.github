# Shared Assets

Place images used by more than one common guide in this directory.

Suggested conventions:

- Use lowercase, descriptive, hyphen-separated filenames.
- Prefer SVG for simple diagrams and PNG or WebP for screenshots.
- Crop screenshots to the relevant interface area and remove personal information.
- Include meaningful alternative text whenever an image is embedded in a guide.
- Keep product photographs and model-specific diagrams in the corresponding product repository.

- `coordinator-placement.svg`
- `wifi-zigbee-channel-overlap.svg`
